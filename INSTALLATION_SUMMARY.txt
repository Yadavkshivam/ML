🔄 DATA FLOW

Phone (Expo Go)
    ↓
    User takes fingerprint photo aligned in reticle
    ↓
    Image sent as HTTP POST to backend
    ↓
Backend (Flask API on 10.45.68.58:8000)
    ↓
    Image received and preprocessed (256x256 resize)
    ↓
    ResNet50 model inference → prediction + confidence
    ↓
    VGG16 model inference → prediction + confidence
    ↓
    Consensus vote: majority from 2 models
    ↓
    Return JSON: {results: [{model, predicted_class, confidence, probabilities}, ...]}
    ↓
Phone (Expo App)
    ↓
    Display consensus blood group
    ↓
    Show individual model predictions
    ↓
    User can scan again or exit
