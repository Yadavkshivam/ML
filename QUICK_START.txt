🔍 WHAT THE APP DOES

1. HOME SCREEN
   → Overview and introduction

2. GUIDANCE SCREEN
   → Instructions for fingerprint placement
   → "Stamp inked finger on white paper, place flat, capture"

3. CAMERA SCREEN
   → Live camera feed
   → Reticle overlay to guide alignment
   → "CAPTURE" button to take photo

4. PREVIEW SCREEN
   → Review the captured image
   → "Proceed" to analyze

5. RESULT SCREEN
   → Consensus Blood Group (e.g., "A+")
   → Individual model predictions:
      • ResNet50: A+ (95.2% confidence)
      • VGG16: A+ (92.1% confidence)
   → Top 3 blood group probabilities per model
   → "SCAN AGAIN" button to start over

❌ TROUBLESHOOTING

Q: "CONNECTION ERROR — CHECK SERVER"
A: 
   1. Check phone is on same WiFi as computer
   2. Verify backend is running: curl http://10.45.68.58:8000/
   3. Check firewall isn't blocking port 8000
   4. Try closing and reopening Expo Go app

Q: "Cannot find QR code in terminal"
A:
   1. Look for output that says "Scan with Expo Go"
   2. Or press 's' in the metro bundler to show QR again
   3. Terminal might be scrolled up - scroll down

Q: "App loads but camera doesn't work"
A:
   1. Grant camera permission when phone asks
   2. Close app and reopen
   3. Restart Expo: Ctrl+C in terminal, then npm start again

Q: "Prediction is very slow"
A:
   This is normal! First prediction loads 94MB ResNet50 model.
   Wait 30-45 seconds on first prediction.
   Subsequent predictions are faster (5-10 seconds).
